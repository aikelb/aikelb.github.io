# Design / UX review

Reviewed 2026-06-11 against live renders of the dev server (desktop, narrow, and mobile
viewports; dark and light themes) and the pinned references in
[260611.00-design-references.md](260611.00-design-references.md). Goal: a modern portfolio
appealing to all publics, not just developers, while keeping the humble/authentic voice.

## Overall verdict

The foundation is strong: a coherent visual identity (calm dark theme + genuinely lovely
"washi paper" light mode), good content hierarchy on the home page (hero → timeline →
notebook → profile snapshot), tasteful motion (aurora glow, scroll reveals, expanding
timeline), no mobile overflow, and `prefers-reduced-motion` properly handled
([redesign.css:1411](../../themes/default/css/redesign.css)). The personality is there —
the cats card is exactly the right kind of touch.

The gap to the references is in two places: **the terminal jargon framing works against the
"all publics" goal**, and **the surfaces are static** — cards and hero have none of the
hover/looping life that defines leanrada and reactbits.

## Findings, prioritized

### 1. Terminal jargon limits the audience 🔴 (S–M effort, content + CSS)

Section labels read `[01 // TIMELINE]`, `→ // historical_timeline`, `[career_metrics]`,
`[environment_nodes]`, `→ // browse_all_notes (13)`. For developers it's charming; for a
recruiter, a journalist, or a parent it's noise — and these labels carry the page's
information scent. The references get personality without the cost: leanrada uses warm
human microcopy + custom icons; mise uses simple section numbering (01/02/03) with plain
words and a playful metaphor.

**Recommendation:** keep the monospace accent style and the numbering, humanize the words —
`[01 · Timeline]`, `Browse all notes (13) →`, `Career at a glance`, and let
`[environment_nodes]` become something like `Office staff` (funnier *and* clearer). The
mono font + brackets already deliver the dev vibe; the vocabulary doesn't need to.

### 2. The hero has no visual anchor or color moment 🟡 (M)

Above the fold the site is text-only and nearly monochrome — the accent green appears only
in the active-nav pill. mise opens with a logo + confident tagline; leanrada with playful
visuals. A portfolio hero for "all publics" benefits from one human/visual element:
a small avatar or hand-drawn mark, or a subtle generative canvas accent (see §5) behind the
greeting, plus one warmer accent use (e.g. the underlined word, or the two hero links
restyled as small pill buttons). Note the SVG dither filter (`#aurora-dither`,
[base.njk:81-92](../../themes/default/_layouts/base.njk)) is defined but the aurora is so
faint it barely registers at default scroll position — either let it breathe or repurpose
the budget for a hero accent.

### 3. Cards are static — the biggest reference gap 🟡 (M, high payoff)

The profile-snapshot grid is already a bento layout, but only the cats card has any life.
Cheap-to-build patterns from the references, all CSS or tiny JS, all behind
`prefers-reduced-motion`:

- **Spotlight hover** (reactbits): radial-gradient that follows the cursor on
  `.metadata-card` — ~15 lines of JS setting `--mx`/`--my` custom properties + one CSS rule.
- **Padding/lift shift on hover** (leanrada): cards that subtly grow padding or shift
  content on hover rather than just changing border color.
- **One looping detail, not many**: e.g. the `[active_stack]` tags gently cycling emphasis,
  or a slow shimmer on the metrics numbers. One loop on the page is charm; five is a casino.
- **Tag pills as links**: the stack/expertise tags look interactive but aren't — either make
  them link to `/tag/...` pages (they exist!) or visually flatten them.

### 4. Writing index is a bare list 🟡 (S–M)

`/writing/` renders title + tag pills + verbose date ("Sunday, 12 October 2025") rows.
Problems: slide decks and articles are visually identical; dates dominate; "Less than 1
minute to read" shows on slide entries where it's meaningless. Recommendation: a type
badge or icon per entry (🎞 slides / ✍ note), short dates (`Oct 2025`), suppress reading
time for slides, and consider year-group headers. This pairs with the slide-embed work in
[260611.03-content-review.md](260611.03-content-review.md).

### 5. Motion opportunities from reactbits (L, optional, do after 1–4)

If you want one signature animation, make it the hero/background: a single lightweight
canvas (dot grid that subtly reacts to the cursor, or a slow wave field in the theme
colors), capped at ~60 lines of vanilla JS, paused on `prefers-reduced-motion` and on
`visibilitychange`. This would replace the (currently invisible) aurora rather than stack
on top of it. Avoid importing animation libraries; the site's performance is a feature.

### 6. Small fixes (S)

- **Timeline rows aren't keyboard-accessible**: `.work-entry-head` is a `<div @click>`
  ([home.njk:34](../../themes/default/_layouts/home.njk)) — not focusable, no
  `aria-expanded`, unusable by keyboard/screen reader. Make it a `<button>` with
  `:aria-expanded="open"`.
- **Footer shows "loading weather…"** until the API answers — render nothing until data
  arrives instead of a loading state for a decorative widget.
- **14 inline `style="…"` attributes in home.njk** (hero + section spacing) — move to
  classes in redesign.css; inline styles dodge the design tokens and make theme changes
  miss spots.
- Hero quick-links (`→ // historical_timeline`, `→ // slides`) duplicate the main nav at
  lower contrast — fold into §1's relabeling or drop one.

## What NOT to change

- The light "washi" palette and the dark default are both good — don't redesign the color
  system, extend it.
- Voice and density of the home page: the three-paragraph hero is honest and readable.
- The cats card. Never touch the cats card.

## Suggested order

1. Humanize labels (§1) + small fixes (§6) — one short pass, mostly find/replace + a11y.
2. Card hover personality (§3) + writing index (§4).
3. Hero visual anchor (§2), then — only if still wanted — the signature canvas (§5).
